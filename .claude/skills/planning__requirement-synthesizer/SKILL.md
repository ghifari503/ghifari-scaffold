# Requirement Synthesizer

## Purpose
Turn raw notes and founder decisions into implementation-ready product requirements.

## Required Inputs
Read:
- `artifacts/context/PROJECT_CONTEXT.md`
- `artifacts/context/BUSINESS_CONTEXT.md`
- `artifacts/context/PRODUCT_SCOPE.md`
- `artifacts/architecture/DECISION_LOG.md`
- `templates/brd_template.md`
- `templates/prd_template.md`

## Process
1. separate business goals from product requirements
2. define in-scope and out-of-scope
3. list actors
4. generate feature list
5. write user stories
6. define acceptance criteria
7. define functional requirements
8. define non-functional requirements
9. capture assumptions and risks

## Output
Produce:
- BRD draft
- PRD draft
- feature list
- user story list
- acceptance criteria
- FR/NFR list
- scope summary
- risk and assumptions list

## Rules
- Requirements must be testable.
- Avoid vague language.
- If information is missing, flag it explicitly.
- If there is a contradiction, call it out and suggest a founder decision.
