# Documentation Guide

This folder provides navigation and operational explanations for the scaffold. Policies and enforceable rules remain in `guardrails/`; runtime instructions remain in `AGENTS.md`.

## Start Here

- `DEVELOPMENT_WORKSPACE.md`: target-project attachment layout and Git isolation.
- `GRAPHIFY_INTEGRATION.md`: optional, explicit-consent Graphify workflow.
- `ARCHITECTURE.md`, `PROJECT_STATE.md`, `DECISIONS.md`, `NEXT_STEPS.md`: scaffold orientation and navigation.
- `REPOSITORY_GOVERNANCE.md`: contribution, branch, and review expectations.
- `ANTIGRAVITY_SETUP.md` and `CLAUDE_CODE_VSCODE_SETUP.md`: runtime-specific setup notes.
- `overview/`: compatibility navigation documents and high-level reference material.

Project requirements, feature documentation, design references, and prototypes belong in root `dev-doc/[feature-name]/`.
