# DECISIONS

This file is the stable quick-entry document for important technical and product decisions.

## Primary Source Of Truth
- `artifacts/architecture/DECISION_LOG.md`

## Purpose
Use this file as the obvious place to look when asking:
- what technical decisions have been made
- which decisions are final
- which tradeoffs were approved

## Decision Categories
- architecture decisions
- framework decisions
- route decisions
- migration decisions
- refactor or revamp approval decisions
- exceptions and constraints

## Reading Rule
- Read `artifacts/architecture/DECISION_LOG.md` for the full historical record.
- Do not overwrite decisions marked final unless a new decision explicitly supersedes them.

## Expected Maintenance
Whenever a meaningful change is approved, update:
1. `artifacts/architecture/DECISION_LOG.md`
2. any impacted operational docs
3. this quick-entry file only if the reading path changes
