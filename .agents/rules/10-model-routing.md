# Odonplay Antigravity Model Routing Rule

Configure this workspace rule as **Always On** in Antigravity IDE.

Read and follow @../../guardrails/system/ANTIGRAVITY_RUNTIME_POLICY.md before coding, refactoring, test creation, migration, dependency work, or scaffold generation.

Choose the model automatically when the runtime exposes that capability. Never ask the founder to choose a model. If the active Antigravity turn cannot switch or launch the required worker, preserve the active model truthfully and follow the policy's `model_switch_unavailable` rule.
