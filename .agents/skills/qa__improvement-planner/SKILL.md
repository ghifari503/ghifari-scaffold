# Improvement Planner

## Purpose
Close the loop after a feature or release by turning learnings into action.

## Required Inputs
Read:
- `artifacts/improvement/LEARNINGS.md`
- `artifacts/architecture/DECISION_LOG.md`
- relevant QA summaries
- `templates/improvement_template.md`

## Output
Produce:
- current issue summary
- what worked
- what failed
- root cause hypotheses
- prioritized backlog
- technical debt list
- recommended next iteration
