# Security Policy

## Reporting A Vulnerability

Do not create a public issue for suspected vulnerabilities, exposed credentials, unsafe workflow bypasses, or supply-chain concerns in skills.

Report the concern privately to the repository maintainer through the Odonplay internal communication channel. Include affected paths, impact, reproduction steps when safe, and whether credentials or user data may be exposed.

## Response Expectations

Maintainers will acknowledge the report, assess severity, coordinate remediation, and record only safe summaries in repository artifacts. Do not include secrets, exploit payloads, or sensitive raw logs in issues, commits, or shared context.

## Skill Supply Chain

External skills must follow `guardrails/system/SKILL_CHECK_POLICY.md`. Validate source, license, reputation, and contents before acquisition; only allowlisted publishers may be acquired automatically.
