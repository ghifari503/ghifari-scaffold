# Founder Interview Template

## 1. Business Problem
- What problem exists?
- Who feels it most?
- Why is it important now?
- What happens if this product does not exist?

## 2. Product Outcome
- What should users be able to do?
- What must be measurable?
- What is the minimum viable outcome?

## 3. Users and Actors
- Primary user
- Secondary user
- Admin/operator
- External system/device

## 4. Scope
- Must-have
- Nice-to-have
- Explicitly out of scope

## 5. Flow
- Entry point
- Main action
- Failure states
- End state

## 6. Technical Context
- platform
- stack preference
- local vs cloud
- sync expectations
- external integrations

## 7. Operational Constraints
- budget
- time
- deployment model
- support model

## 8. Risks and Unknowns
- missing data
- edge cases
- legal/compliance
- reliability concerns

## 9. Founder Decisions Needed
- priorities
- tradeoffs
- non-negotiables
