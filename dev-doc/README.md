# Development Documentation

In a Master Framework, store project development documentation at `dev-doc/[project-folder]/[feature-name]/`. This includes BRD, PRD, design specifications, prototypes, assets, and requirement-conflict decisions.

The canonical Master Scaffold may contain only generic reusable documentation and examples here; it must not contain project-named folders. Do not store development documentation under `development/[project-folder]/`. When a misplaced document is found there, ask the founder for permission before moving it.
