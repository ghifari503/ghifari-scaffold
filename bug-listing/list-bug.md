## Usage

This file is the default bug listing and index.

If the bug list becomes long, split it into named files such as:

```text
bug-listing/pendidikan.md
bug-listing/ruang-belajar-ui.md
bug-listing/siswa-responsive.md
bug-listing/2026-06-regression.md
```

Use `bug-listing/bug-list-template.md` as the format reference.

Do not store passwords, API keys, tokens, or private credentials in this file.
