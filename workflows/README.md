# Workflows

This folder describes repeatable process flows. Workflows explain sequence and responsibilities; `AGENTS.md` and `guardrails/` remain authoritative when a rule conflicts.

## Available Flows

- `greenfield_project_workflow.md`: discovery and controlled bootstrap for a new project.
- `existing_project_onboarding_workflow.md`: intake for cloned or inherited codebases.
- `incremental_feature_workflow.md` and `feature_delivery_checklist.md`: scoped feature delivery.
- `ui_frontend_workflow.md`: design-to-frontend sequence.
- `ai_contributor_lifecycle.md`: cross-runtime contributor evidence overlay.
- `release_to_field_workflow.md` and `software_iot_sync_workflow.md`: release and software/IoT coordination.
- `solo_founder_end_to_end_workflow.md`: founder-oriented end-to-end reference.

Choose the smallest workflow matching the approved task. A workflow never bypasses task classification, founder approval, or the pre-coding gate.
